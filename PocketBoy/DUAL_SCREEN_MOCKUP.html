📊 Data Flow

Game Launch Flow:
1. User taps game tile → Game model updates lastPlayedTime
2. EmulationActivity launches
3. User exits game
4. recordGameSession() called with duration
5. GameStatistics updated in database
6. Bottom screen stats refresh via StateFlow

Achievement Sync Flow:
1. User links RetroAchievements account
2. UserProfileViewModel stores username
3. Next game launch triggers sync
4. API fetches achievements for game
5. Achievements stored in Room database
6. UI updates with achievement list
